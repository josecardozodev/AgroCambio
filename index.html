Como funciona

Neste projeto, o lado cliente (client side) é tudo o que roda no seu navegador: o HTML, o CSS e o JavaScript que você baixa ao abrir a página. É o JavaScript que faz a requisição com fetch() à API de câmbio, calcula a conversão da receita e atualiza a tela. O lado servidor (server side) fica em computadores remotos: o servidor da AwesomeAPI, que recebe o pedido e devolve as cotações em formato JSON, e o servidor web da máquina virtual Linux, que apenas entrega os arquivos do site ao navegador, sem fazer nenhum cálculo.

Fonte dos dados: AwesomeAPI Cotações (docs.awesomeapi.com.br).
